# Claude API Prompt Draft

basil-ai が Claude API(`claude-opus-4-7`)に渡すプロンプトのドラフト。
実装は `raspi/claude_client.py` が担当する。

---

## 設計方針

- **入力**: 鉢の現在画像 + 直近 24h のセンサー時系列(集約) + 前回の判断ログ
- **出力**: JSON ひとつ(自由テキスト混入を禁止する)
- **役割**: 「室内バジルを枯らさないように管理するホームガーデナー」
- **重要**: Claude の応答は「提案」であり、最終決定は Pi の safety が持つ
  → Claude の出力を過信しない設計を文章側でも伝える
- **Prompt caching**: system メッセージ(長め・固定)と直近 24h の集約部分は
  `cache_control: ephemeral` を付けてキャッシュさせる

---

## メッセージ構造

### system メッセージ(キャッシュ対象)

```
あなたは室内栽培のバジル(Ocimum basilicum、スイートバジル)を管理する
経験豊富なホームガーデナーです。

このプロジェクトは「AI に水やり判断をさせる」YouTube 企画の一部です。
あなたの役割は、与えられた画像と数値から「今、水をやるべきか / やるなら何 ml か」を
判断して JSON で返すことです。

【重要】
- あなたの応答はあくまで「提案」です。最終決定は Pi 側のセーフティガードが行います
- ml は 0〜50 の範囲で、整数で返してください。上限を超える値は自動的にクリップされます
- 「やらない勇気」も積極的に使ってください。過給水のほうが根腐れで致命的です
- 出力は **指定の JSON のみ**。前後に説明文や ``` を付けないでください

【判断材料のヒント】
- バジルは湿り気味を好むが、常時ウェットは根腐れの原因
- 土壌水分 40% 以下かつ鉢重量が減少傾向なら給水候補
- 葉の下垂 / 葉色の薄さは水分不足サインになり得るが、光量不足でも似た症状が出る
- 直近 3 時間以内に給水済みの場合は、原則として追加給水しない
```

### user メッセージ(動的)

user メッセージは以下の 3 ブロック構成。

1. **画像**(image blockcamera が直前に撮った jpg)
2. **直近 24h のセンサー集約**(テキスト、キャッシュ可能部分)
3. **現在の瞬時値と前回判断**(テキスト、毎回変わるのでキャッシュしない)

#### 集約サマリ例

```
## 直近 24h のセンサー集約(AI 個体)

| 指標              | min   | mean  | max   | trend(前半→後半) |
|-------------------|-------|-------|-------|-------------------|
| 気温 (°C)         | 21.0  | 23.5  | 26.2  | 23.0 → 24.1       |
| 湿度 (%)          | 40.2  | 47.8  | 55.1  | 49.0 → 46.6       |
| 照度 (lux)        | 12    | 980   | 2100  | LED 06-22h 点灯   |
| 土壌水分 (%)      | 34.5  | 38.2  | 42.0  | 41.0 → 35.0       |
| 鉢重量 (g)        | 1425  | 1439  | 1452  | 1450 → 1428       |
| タンク空          | いいえ |       |       |                    |
```

#### 現在値と前回判断例

```
## 現在(2026-04-23T12:00:00Z)

- 気温: 24.3 °C
- 湿度: 48.1 %
- 照度: 1820 lux
- 土壌水分: 35.8 %
- 鉢重量: 1428 g
- タンク空: いいえ

## 前回の最終決定(2026-04-23T07:00:00Z)

- water: true
- ml: 20(クリップ無し、source=claude_guarded)
- reason: "土壌 33%、重量減、朝観察"

## あなたの応答

下記スキーマの JSON のみを返してください。
```

## 応答スキーマ(Claude に返させる JSON)

```json
{
  "water": true,
  "ml": 25,
  "confidence": 0.72,
  "reason": "葉の下垂は軽微だが土壌 35.8%、鉢重量が 24h で -22g、前回給水から 5h 経過。少量の給水が妥当",
  "observations": [
    "葉の色は健康的な緑",
    "土壌表層はやや白っぽく乾燥",
    "茎は直立しており徒長なし"
  ],
  "warnings": []
}
```

| フィールド | 型 | 必須 | 説明 |
|-----------|----|------|------|
| `water` | bool | ✓ | 給水するかどうか |
| `ml` | int | ✓ | 給水量。`water=false` のときは 0 |
| `confidence` | float | ✓ | 0.0〜1.0 の自信度 |
| `reason` | string | ✓ | 判断理由(日本語、動画テロップに使える文体) |
| `observations` | string[] | ✓ | 画像からの観察(葉・茎・土壌表層) |
| `warnings` | string[] | ✓ | 異常の兆候(空配列可) |

---

## パース失敗時のフォールバック

Claude が指定スキーマ外で返してきた、JSON パースに失敗した等の場合、
Pi 側は **Claude 応答を破棄して `source=rule_based` で判断する**。
このときの原文は `api_logs.error` 列に記録する。

---

## トークン節約

- system メッセージは固定 → `cache_control` で丸ごとキャッシュ
- 直近 24h 集約もキャッシュ対象(観察時刻間隔が短い日は大部分が同じ)
- 画像は毎回変わるのでキャッシュ対象外
- 応答は `max_tokens` を 600 程度に制限(reason と observations で十分埋まる)
